# Zeeshan & Brothers BMS — Downloads

Business Management System for **Zeeshan & Brothers (Electric Power Solutions)**.

## Install

1. Open the **[Releases](../../releases/latest)** page.
2. Download **`Zeeshan and Brothers BMS Setup x.x.x.exe`** and run it.
3. If Windows shows a blue "Windows protected your PC" screen, click **More info** and then **Run anyway**.

## Updates

The program checks for new versions by itself. When one is ready you will see a message — click **Restart and update**. Your data is never touched by an update.

---
This repository only holds the installers. It contains no source code and no business data.
